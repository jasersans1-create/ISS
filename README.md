# ISS Tracker

ISS Tracker is a web-based dashboard that tracks the current location of the International Space Station and displays mission-related information.

The goal of this project was to build a simple but interactive "mission control" style interface where users can view the ISS position, follow its movement, and explore information about the crew onboard

## Features

- Real-time ISS location tracking
- Interactive map showing ISS position
- ISS crew information
- Space-themed dashboard interface
- Live updates of tracking data

## Running Locally

Clone the repository:

```bash
git clone https://github.com/jasersans1-create/ISS.git
```

Navigate into the project folder:

```bash
cd ISS
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
